# Atividade 2 - Tela de Cadastro

Página de cadastro desenvolvida com HTML e CSS, com layout de duas colunas:
uma imagem de destaque de um lado e o formulário de cadastro do outro. Feita
como exercício da disciplina de desenvolvimento web.

## Sobre o projeto

O objetivo foi montar um formulário de cadastro completo e organizá-lo dentro
de um container dividido em duas partes (imagem e formulário). A página contém:

- Título principal
- Campo para E-mail ou Usuário
- Campo para E-mail
- Campo para CPF
- Campo para Celular
- Campo para Senha
- Campo de Data de nascimento
- Seleção de Gênero
- Checkbox de aceite dos termos de uso
- Botão de envio

## Tecnologias

- HTML5
- CSS3 (Flexbox para o layout de duas colunas e centralização)

## Estrutura de arquivos

```
atividade2-cadastro/
├── index.html
├── style.css
├── tela.png
└── README.md
```

## Como executar

1. Baixe os arquivos e mantenha todos na mesma pasta (incluindo a imagem).
2. Abra o arquivo `index.html` com um duplo clique (ele abre no navegador).

Não precisa de servidor nem de nenhuma instalação.

## Detalhes de estilo

- Layout dividido em duas colunas com Flexbox (`lado-imagem` e `lado-form`)
- Fundo cinza claro: `#f0f2f5`
- Botão verde: `#28a745`
- Campos com cantos arredondados, efeito `:focus` na borda e `:hover` no botão
